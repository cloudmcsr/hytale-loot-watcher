Loot Table Viewer

Quick Start

  • Browse: Sidebar has Structures and Loot Tables (mobs, blocks, interactions, crops...)
  • Categories: Dropdown in the sidebar header; a specific category lists its files directly
  • Names: Entries show display names and ids — both are searchable
  • Highlight: Funnel icon + partial search term (glows matches, collapses the rest)
  • Collapse: ROLL headers or card titles
  • Copy coordinates: Click coordinate chips (in Structures)

Understanding Loot Tables

What you seeMeaning
ROLL (pick N)Picks N items among the slots below
INDIVIDUAL ROLLS (N)Each slot is its own independent roll — the badge is that roll's chance
Included: [Table]Another loot table rolled inline
% on item slotChance the item appears; 100% = always
% on a ROLL rowChance the roll happens; none = always
Nothing slotThe pick rolled no item

Generating Data for Other Versions

You can generate data for any Hytale version using the files included with the game. No coding skills required!

Locate Assets.zip

Go to your Hytale installation folder and find this file:

.../Hytale/Install/package/latest/Assets.zip

Extract Required Folders

Open Assets.zip and navigate into Assets/Server/.

Extract these folders to the same folder as this tool:

  • Prefabs (contains structure data)
  • Drops (all loot tables: chests, mobs, blocks, interactions)

Run the Script

Run the script below to generate a new mapped_prefabs_data.json file. Then run scripts/generate_app_data.py to merge it with the Drops folder into data.js.
